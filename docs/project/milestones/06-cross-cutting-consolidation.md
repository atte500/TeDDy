# Milestone: Cross-Cutting Consolidation

- **Status:** Planned
- **Specs:** TBD

## Goal
Eliminate duplicated literals, helpers, and test doubles that currently live in more than one place and must be kept in manual lockstep. Each duplication is a latent drift bug: when one copy changes, the others silently diverge. This milestone single-sources every such concept so the codebase has one authoritative location per concern, consolidates split test organization, and performs a bounded Failure-Transparency sweep. Every item was previously parked in the retired `## Technical Debt` section of `docs/project/PROJECT.md`; with that holding pen removed, each is now scheduled here as an explicit requirement.

## Requirements
1. **Single-source Production Literals & Helpers:** Consolidate duplicated constants (encoding name, env-var name, editor sentinel, user request format, awaiting_reply key) and helpers (API key check, MESSAGE detection, preservation-arm decision).
2. **Align `## User Request` Rendering:** Align bare-fence format and sanitizer behavior between template and append paths.
3. **Provider Resolution behind `ILlmClient`:** Move litellm provider resolution behind a single `ILlmClient` method.
4. **Extract Shared Test Fakes:** Extract in-memory filesystem, termios, and ask-loop fakes into `tests/harness/setup/`.
5. **Consolidate Inbound Port Contract Directory:** Merge `tests/suites/unit/ports/inbound/` into `tests/suites/unit/core/ports/inbound/`.
6. **Failure-Transparency Sweep:** Narrow or add debug logging to broad `except` blocks across 12 named modules.
7. **Establish `TeddyError` Root Custom Exceptions:** Create `TeddyError` root class and re-parent all custom domain and boundary exceptions.
8. **Specialize Domain Exceptions for Overloaded `ValueError`s:** Introduce `SessionNotFoundError`, `WorkingDirectoryEscapeError`, and `UnknownActionError`.
9. **Reconcile Validation Error Naming:** Disambiguate `InvalidPlanError`, `PlanValidationError`, and rename `ValidationError` DTO to `ValidationFinding`.
10. **Translate `WebScrapeError` Boundary:** Wrap scraping/network exceptions and eliminate silent empty strings in `WebScraperAdapter`.
11. **Single-source Action-Type Registration Table:** Collapse multi-file action registration into a single source of truth.
12. **Migrate Project Tooling to `justfile` and `scripts/`:** Replace `Makefile` and `make/*.mk` with `justfile`, move `commit`, `ci-watch`, `logs`, and `probe` logic into Python helpers in `scripts/`, and add unit tests for `ci-watch` attribution logic. The migration also corrects the run-registration wait that `ci-watch` and `probe` share through `RETRY_POLLS` (10) × `RETRY_SLEEP` (2): about 20 seconds in practice, and short enough on this repository's push rate to expire before GitHub registered a run that did exist, blocking the session with a false `no run registered` fail-safe. The migrated script MUST size the wait for an active trunk-based repository, expose it as a configurable default, and apply it to both consumers.

## Constraints
- **Test Harness Strategy:**
    - **Single-source proof:** For each extracted constant/helper, add or update a test that imports the canonical definition from both former consumer sites and asserts identity — so a future re-duplication fails loudly.
    - **Shared-fake adoption:** Migrate the bespoke fakes onto the shared harness fake and delete the local copies; the full suite MUST remain green.
    - **Directory consolidation:** `git mv` the straggler contract test into the canonical directory and fix all import and doc references.
    - **Failure-Transparency sweep:** For each broad `except`, either narrow the caught exception type or add debug-level logging before swallowing; legitimate "safe to ignore" cases MUST keep their explicit comment.
- **Poka-Yoke:** Prefer a shared harness fixture over per-suite duplication so the rule-of-three threshold can never be silently exceeded again.
- **No New Behavior:** Every change MUST preserve existing runtime behavior and pass the full suite; this is a consolidation program, not a feature program. **Documented exception:** the `## User Request` bare-fence decision (slice 16) is an explicit product change requested on 2026-11-06, so it alters rendered report bytes and the assertions that pin them; every other item in this milestone stays behavior-preserving.

- **Split inbound-port contract tests:** `test_run_plan_use_case_contract.py` lives in `tests/suites/unit/ports/inbound/` while every other `core.ports.inbound` contract test lives in `tests/suites/unit/core/ports/inbound/`. Consolidate into one canonical location.
- **`InitService` manifest constant:** `_TEMPLATE_FILES` and `_PROMPT_FILES` are module-level constants, but the config manifest is an inline string literal inside `_init_config_dir`. Extract a symmetric `_CONFIG_FILES` module constant single-sourced with its consumer.
- **Duplicated production literals (must stay in lockstep):** the `cl100k_base` encoding name (`litellm_adapter.py` + `cli_helpers.prewarm_imports`); the `TEDDY_LLM_API_KEY` env-var name (`session_cli_handlers.py` + bundled `config.yaml`); the `"disabled"` editor sentinel (`console_tooling.py` + `session_cli_handlers.py` + `test_environment.py`); the "Editor is disabled in config" message (`console_interactor_ask_loop.py` + `console_interactor.py`); the `## User Request` section format (`execution_report.md.j2` + `SessionLifecycleManager._append_user_request` + the `^## User Request` preservation-detection regex in `session_service.py`, a third lockstep site that silently stops matching whenever the heading text changes); the `awaiting_reply` flag key (`session_orchestrator.py` + `session_lifecycle_manager.py`).
- **`## User Request` render divergence:** both producers route the message body through the shared `embed_in_fence` primitive, so the fence mechanics themselves are single-sourced, but the bytes around the block are not identical. `MarkdownReportFormatter` rstrips every rendered line before its fence-tracking loop (`markdown_report_formatter.py:103`), so fenced content loses per-line trailing whitespace on the template path; `SessionLifecycleManager._append_user_request` writes the message with no sanitizer pass at all. The sanitizer also toggles its in-fence state on a line whose stripped text begins with a fence run, rather than comparing fence width, so a widened wrapper that itself contains a fence line flips the state and lets the blank-line collapsing rules run inside the block. Align the two paths and decide whether the tracker should compare fence width.
- **`## User Request` bare fence:** both producers render the block with an empty language tag instead of a `text` tag, matching `## User Reply`, which already emits an empty tag. `docs/project/specs/report-format.md` does not describe this section and does not pin the language tag, so no spec change is required; the change touches `execution_report.md.j2`, `SessionLifecycleManager._append_user_request`, and the byte-exact assertions that hardcode a text-tagged User Request block across the unit and acceptance suites, to be enumerated tests-first when the slice is drafted.
- **Duplicated production helpers:** the "does this model require an API key?" check (`LiteLLMAdapter.validate_config` + `_llm_model_requires_api_key`); the MESSAGE-action detection iteration (`session_orchestrator.py`); the preservation-arm decision (`SessionService.transition_to_next_turn` + `preserve_turn_in_session_context`); the two function-local `session_orchestrator` imports in `session_lifecycle_manager.py`.
- **Shared test fakes (rule of three met):** three dict-backed `InMemoryFileSystem` fakes (`test_session_repository_meta_contract.py`, `test_session_service_turn_meta.py`, `test_session_lifecycle_resume_message_persistence.py`); four `termios` fakes (`test_tty_guards.py`, `test_terminal_cooked_mode_restore.py`, `test_restore_cooked_mode.py`, `test_terminal_quit_key_listener_reader.py`); ask-loop editor/tooling fakes across three suites. Also extract a `ports_fixture` of pre-configured port mocks to reduce mock-poisoning risk. Consolidate into `tests/harness/setup/`.
- **Duplicated harness temp-root boilerplate:** `tests/harness/setup/model_registry_cache.py` and `hook_shims.py` each duplicate the `tempfile.mkdtemp()` + `rmtree` lifecycle; extract a shared temp-root helper.
- **TUI diff-routing decision:** the routing predicate reads the static `_DIFF_FLAGS` table while `get_diff_viewer_command()` honours the `diff_flags` override, so a user-supplied `diff_flags` is silently ignored for unknown editors. Single-source the "is this a registered diff editor?" decision.
- **MRP resource-root test setup:** the real-`tmp_path` `MRP.md` resource-root construction in `test_prompt_manager.py` is duplicated in `test_prompt_resolution.py`; extract a shared harness helper.
- **Contract-violating session doubles:** `test_session_replan_loop.py`, `test_session_start_resequencing.py`, and `test_resume_message_threading.py` build their own containers and register a bare `Mock(spec=IInitUseCase)` whose `check_drift()` returns a dynamic Mock (no `__len__`). Extract a shared pre-configured session-container / ports fixture so doubles stay contract-faithful.
- **Silent error swallowing (Failure Transparency):** broad `except` blocks without logging across `cli_helpers.py`, `local_file_system_adapter.py`, `shell_adapter.py`, `web_scraper_adapter.py`, `openrouter_hydrator.py`, `yaml_config_adapter.py`, `action_executor.py`, `context_service.py`, `session_pruning_service.py`, `session_repository.py`, `update_checker.py`, and `io.py`. Narrow the type or add debug-level logging; keep legitimate "safe to ignore" comments. The hydrator carries the sharpest gap in this list: `_fetch_models` catches `requests.RequestException` and `ValueError` and returns an empty catalog with no log line, while the adapter's own persistent-cache path debug-logs its equivalent failure. A network outage is therefore invisible in the logs and reaches the caller only as absent metadata, so the sweep must promote that catch to a narrowed or debug-logged one.
- **Unused action-param threshold path:** `resolve_similarity_threshold` in `validation_rules/helpers.py` reads an action parameter named `edit.similarity_threshold` that no caller sets, because the global config lookup already supplies the threshold. Confirm no plan producer emits that parameter, then delete the dead branch.
- **`SessionLifecycleManager` component design doc:** `SessionLifecycleManager` owns the presence-gated resume prompts (`_can_prompt_user`, `_resolve_blank_message`) and the pipeline pass-through across the COMPLETE_TURN delegation, but has no component design document. Its four consumer docs — the CLI adapter, `SessionOrchestrator`, `ConsoleInteractor`, and `ISystemEnvironment` — each reference its behaviour with no contract page to link to, so the presence gates are documented only from the outside. Add `docs/architecture/core/services/session_lifecycle_manager.md` following the component-design template (purpose, consumers, dependencies, class invariants, port contracts, operations) and link it from the Component Map in `docs/architecture/ARCHITECTURE.md`.
- **`TeddyError` root Custom Exceptions:** Introduce a root base exception `class TeddyError(Exception): pass` in `src/teddy_executor/core/domain/models/exceptions.py`. Re-parent all existing custom domain and boundary exceptions (`ConfigurationError`, `FileAlreadyExistsError`, `MultipleMatchesFoundError`, `SearchTextNotFoundError`, `WebSearchError`, `InvalidPlanError`, `LlmApiError`, `PlanValidationError`) under `TeddyError`. Update outer controllers (CLI, TUI, ExecutionOrchestrator) to catch `TeddyError` for clean user-facing failure reporting, letting unexpected runtime bugs (`AttributeError`, `IndexError`, contract assertion failures) fail-fast with full tracebacks. The root class itself lands early in slice `00-02-pdf-text-extraction` so `PdfExtractionError` can inherit from it; this item then re-parents the existing exceptions and updates the outer controllers.
- **Domain exception specialization for overloaded `ValueError`s:** Replace generic built-in `ValueError`s with dedicated `TeddyError` subclasses:
  - `session_manager.py` / `session_service.py`: replace overloaded `ValueError` with `SessionNotFoundError` (missing session or slug resolution failure), `SessionAlreadyExistsError` (collision on rename), and `InvalidSessionPathError` (path outside session).
  - `shell_executor.py` / `shell_adapter.py`: replace generic `ValueError` with `WorkingDirectoryEscapeError` when `cwd` is absolute or resolves outside the project root.
- **Validation error naming and layer seam reconciliation:** Clarify and disambiguate overlapping "validation" names across layers: `InvalidPlanError` (AST and structural Markdown parsing syntax failures in `plan_parser.py`), `PlanValidationError` (semantic pre-flight validation rule violations in `validation_rules/helpers.py`), and `ValidationError` (report DTO dataclass, not an exception, in `models/plan.py`).
  - Ensure documentation, error messages, and type hierarchies reflect this layer seam clearly.
- **`WebScrapeError` boundary translation and silent-empty elimination:** `WebScraperAdapter` currently leaks raw third-party (`trafilatura`) and HTTP/socket exceptions across `IWebScraper.get_content`, while `docs/architecture/core/ports/outbound/web_scraper.md` claims it "raises a web-content error". Introduce `class WebScrapeError(TeddyError): pass` in `exceptions.py` and wrap all scraping and network failures in `WebScraperAdapter`. The silent empty-string returns in `_get_content_impl` (empty User-Agent rotation, falsy `trafilatura.extract`) must be replaced with a typed `WebScrapeError` in the same pass, so a caller can distinguish a genuinely empty page from a blocked or unrenderable fetch; the local and remote PDF paths from slice `00-02` depend on that distinction.
- **Exception inheritance standardization:** Eliminate inconsistent base classes across existing domain exceptions (`FileAlreadyExistsError` inheriting from `FileExistsError`/`OSError`, `SearchTextNotFoundError` inheriting from `ValueError`, and others inheriting directly from `Exception`). Standardize on pure or explicit dual inheritance under `TeddyError` so caller error catching is deterministic and never accidentally caught by standard library exception handlers.
- **`ValidationError` DTO renaming:** Rename `ValidationError` in `src/teddy_executor/core/domain/models/plan.py` to `ValidationFinding` (or `ValidationIssue`). The current dataclass is a value object representing an inspection finding in `ExecutionReport`, but its `*Error` suffix collides conceptually with `InvalidPlanError` and `PlanValidationError` exception classes.
