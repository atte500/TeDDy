# TeDDy v0.1.16

Features:
- Session interrupt & resume: press `q` (or `Ctrl+C`) to stop a running session immediately — the in-flight action is interrupted, the remaining actions are skipped, and the report is still written so the full audit trail is preserved; then continue with `resume -m "..."` to inject your next turn and skip the interactive prompt (process-global quit-key listener, two-phase interrupt guard, stdin-ownership claim)
- Session name collision guard: exclusive session-root claims, an atomic `create_directory_exclusive` filesystem port, suffix-retry via continuation names, and a sibling-integrity gate for the turn-100 migration
- Resume enhancements: `-a/--agent` flag for mid-session agent switch, and session resolution by slug as a fallback when the name is not an exact match
- LLM API-key configuration: `${VAR}` interpolation in `config.yaml`, `.teddy/.env` scaffolding at init, an additive API-key preflight gate, and a provider-aware key requirement with a cleaner prompt
- Editor validation & discovery: PATH scanning with a curated `KNOWN_EDITORS` list, interactive selection persisted to `.teddy/config.yaml`, unknown-editor fallback to an annotated diff, a `diff_flags` config override, and a `"disabled"` sentinel
- Editor setup decoupling: `isatty()` terminal-availability seam, a `setup_editor` preflight override, and an editor-setup hint for non-PATH editors
- Windows startup latency: prewarm the tiktoken encoding, persist the OpenRouter model-registry cache, thread project context through the lifecycle to eliminate a redundant gather, and add a pre-commit compare-and-skip guard
- Cost calculation accuracy: broadcast cache-pricing rates from the OpenRouter hydrator, accumulate retry-attempt costs in the planning loop, and log tiered cost-computation failures
- Configuration: tri-state `--yolo` flag with a `yolo_default` config fallback (`--no-yolo` to force interactive), and genericized provider routing that drops the `--provider` flag in favor of config passthrough
- CLI: accept repeated `-c/--context` flags, with comma-separated compatibility
- Session turn numbering: resolve the numerically-latest turn past 99 in the single-folder layout, and embed context files and URLs verbatim
- Deprecate `--console` mode: remove the `--console`/`--tui` flag, collapse the reviewer registry to TUI-only, and drop residual `ui_mode` references

Fixes:
- Edit matcher: rescue literal multi-line FIND blocks at full match score, and gate EDIT ambiguity detection on the effective similarity threshold
- Report: order scalar action metadata under Status, blank-line the User Request section, classify content render placement in a single pass, and unify MESSAGE rendering across pipeline and stop-again paths
- Terminal: re-enable ISIG/IEXTEN in cooked-mode restores, restore the terminal after console ask-loop editor exit, and propagate Ctrl+C from the console ask prompt
- Session: consume the injected reply on pending communication turns, honor `resume -m` on non-communication PENDING_PLAN turns, run context pruning on the primary session path, and persist the quit-key reader
- Adapters: make `write_file` newline-deterministic for byte-exact persistence, detach Windows fire-and-forget spawns from the parent console, and simplify Windows shell detection to use `COMSPEC`
- Outbound: replace racy `logging.disable` toggles with a thread-safe counted suppression scope
- LLM: fail fast on authentication errors instead of exhausting retries, and point empty-key errors at `.teddy/.env`
- Config: preserve comments when persisting the editor setting, recursively interpolate `${VAR}` tokens in nested structures, and expand tilde in `TEDDY_DIFF_TOOL` resolution
- Update: publish dev pre-releases to PyPI and remove the TestPyPI reference from install commands
- CI: guard the POSIX-only `os.killpg` patch and add a poka-yoke test check
- Prompts: unbracket step-name matching in RPP log extraction
