# TeDDy v0.2.0

## Breaking Changes:
- Prompts and blueprints move from XML to Markdown. Bundled agent prompts are Markdown files in `.teddy/prompts/`, the shared protocol ships as `MRP.md`, and artifact blueprints live in `docs/templates/` instead of inside the prompts. Agents delegate routine commands to Makefile targets (`make test`, `make commit`, `make push`, `make ci-watch`, `make probe`) instead of embedding hardcoded shell commands, so a customized prompt that still embeds commands needs updating. An existing `.xml` prompt override keeps resolving until a same-stem Markdown prompt replaces it.
- The config layout splits the single `execution.*` block into `execute.*` and `edit.*`. An existing block is not migrated: move `execution.default_timeout_seconds` and `execution.max_output_lines` under `execute`, and `execution.similarity_threshold` under `edit`.
- The `--api-key` CLI option is removed. Supplying it now fails with an explicit message.
- Interactive setup moves from `teddy init` to the first `teddy start`. A bare `init` no longer prompts for the API key or the editor.

## Features:
- **Project tree limits:** configurable depth and width caps with explicit omission markers, both limits stated in the structure subtitle, and a lower shipped depth default.
- **Tooling and automation:** the Makefile is the single command surface for tests, commits, pushes, CI checks, and probes, so a runner or flag change happens in one place. `make logs STEP=...` joins the canonical entry points, push and ci-watch are decoupled with failing-step details inline, push attribution skips when no CI is configured, and automated git operations skip the post-commit suite. OpenRouter requests credit usage to TeDDy by default.
- **Template and prompt lifecycle:** `teddy init templates` seeds `docs/templates/`, every agent reads the matching template before creating an artifact, and prompt or template drift is flagged after a bare init.
- **Composable Markdown prompts:** `teddy get-prompt` emits the composed system prompt, and the shared Markdown protocol is appended with the agent name taken from the prompt heading.
- **Workspace awareness:** a session start fast-forwards the workspace before the configuration check, names every skip cause, and reports the outcome in the startup banner.
- **Ad-hoc context export:** `teddy context` accepts repeatable `-c/--context` values with URL and manifest expansion. `--only` exports just the explicit set.
- **Responsive session control:** a quit key interrupts an in-flight planning call on every platform, notices name the pressed key and render on one line, and budget guardrails enforce a limit precedence chain with max turns and max cost.
- **Pipeline default:** non-interactive pipeline runs default to the `assistant` agent.
- **Sharper setup:** editor discovery and classification share one basename normalizer. API-key preflight recognizes local endpoints, writes a placeholder key without prompting, and names the provider with the stripped model.
- **Clearer feedback:** the context payload fences porcelain status, the resume banner shows the `-a/--agent` override, and an injected `resume -m` message echoes as a User Message.
- **Typed configuration:** a fail-fast schema validates documented keys and ranges. `${VAR}` interpolation runs before the typed view is built, the view rebuilds on every write, and workspace health checks honour the new toggles.

## Fixes:
- **Parser and reports:** error headlines name the offending node, and structural failure titles keep the parsed plan heading.
- **Cross-platform reliability:** path normalization strips invisible format characters, line endings stay deterministic on Windows, the mock HTTP server binds to IPv4 loopback, and quit delivery reaches the main thread on POSIX and wakes promptly on Windows.
- **Session polish:** pull skip notices keep the startup banner on `stderr`, disabled gates stay silent, resumed telemetry clears `actual_model`, the banner path normalizes to POSIX, and an abandoned editor draft is discarded.
- **Config integrity:** duplicate keys are rejected, and exact-key precedence holds when a setting is written.
- **Update checks:** the experimental channel queries PyPI, and the background update check fails silently.
- **CI diagnostics:** colon-bearing step names are quoted, the `ci.md` templates are aligned, the attribution base is captured before the push, and `ci-watch` reports only the regressions a push introduced.
- **Make targets:** default targets run cross-platform, probe dispatch routes through the recipe shell, and `ci-watch` failures are diagnosed.
- **Init hygiene:** `docs/templates/` is scaffolded only by an explicit `teddy init templates`.
