# TeDDy v0.1.15

Features:
- Pipeline automation foundation: skeleton slice, case file, and production fixes for session orchestration and action execution in pipeline mode
- Editor validation & discovery (Slice 03-01): spec, milestone, roadmap, and console_tooling architecture documentation
- Parallelized URL fetching in context assembly with reduced timeout (5s)

Fixes:
- Parser: preserve percent-encoding in bare `www.` URLs and during path normalization
- TUI: differentiate CLI vs GUI editors on Windows for `launch_editor` and `preview_edit_diff_viewer`; remove explicit stdio redirection from subprocess calls; fix editor flash read regression
- Web scraper: pass URL to `trafilatura.extract()` for meaningful discard logs; suppress trafilatura logging; cache failed URL fetches
- Session orchestrator: resolve `UnboundLocalError` for `typer` in pipeline mode; fix mislabeled MESSAGE response; print abort-captured user message to terminal
- Action executor: fix pipeline mode MESSAGE break not triggering on real execution
- Dependencies: remove deprecated `typer[all]` extra
- Debug: replace `os.uname` with `platform.platform` for Windows probe compatibility
- Core: downgrade WebReadAction error log level from warning to debug
- CI: prevent concurrency cancellation when new commits arrive (`cancel-in-progress: false`)
- Tests: fix `test_gui_url_temp_file_persists_for_deferred_cleanup` to tolerate unrelated `os.unlink` calls on Windows
- Process: documented release title format (no "TeDDy" prefix) and failed release recovery procedure; added `uv.lock` inclusion note
