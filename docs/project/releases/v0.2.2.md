# TeDDy v0.2.2

## Features:
- **Ambiguous edits are blocked:** an `EDIT` whose `FIND` block matches more than one candidate at or above `edit.similarity_threshold` is rejected with a report naming the exact candidate count, instead of silently editing the wrong block. A single clean match proceeds as before.
- **Plan context cap:** the new `plan.max_lines` setting (default 1500) caps how many plan lines reach the model, and the TUI plan view truncates at the same cap with a plain `[Showing first N of M lines.]` notice. Parsing and plan preservation still read the full file, and a plan below the cap opens in place.
- **Clearer execution reports:** a `MESSAGE` action renders as a top-level `## User Reply` section instead of an action-log entry, and a message-only report omits the action log entirely. File actions headline the basename and carry the full path in a `- **File Path:**` bullet only when the path is nested. An `EXECUTE` command block renders only when the reviewer edited the command or the action did not succeed. `RESEARCH` renders `#### SERP for "<query>"`, drops empty title and description bullets, shows `*(No results returned.)*` for a query with no results, and shows the READ hint only when at least one result exists.
- **Prompts follow user presence:** startup, resume, and pending-plan prompts now depend on whether a terminal is attached (and on `--pipeline`), not on whether the plan review is enabled. `teddy resume -m ""` prompts for a message under `yolo_default: true`, and the resume prompt is worded distinctly from the start prompt.
- **Quieter resume:** workspace bootstrap repairs (pre-commit hooks and git initialization) run silently on resume and stay verbose on start, and the workspace pull and health checks now run on `start` only.
- **Provider-reported cost:** telemetry prefers the completion cost the provider reports over a local registry recompute, reads OpenRouter BYOK upstream spend, and keeps the `$???` placeholder only for a genuinely unpriced model. A free model reads `$0.0000`, and a recorded cost shows even when the model is absent from the pricing registry.
- **Context export without files:** `teddy context --only` now runs without `-c` and omits the `Resource Contents` section entirely.
- **Shipped defaults:** the bundled config's default model no longer carries the `:nitro` suffix, and its comment points at the variant documentation.

## Fixes:
- **Newline fidelity:** authored trailing newlines survive in `CREATE` content and in `EDIT` `FIND`/`REPLACE` blocks, including intra-line fragments.
- **Timeouts:** a timed-out `EXECUTE` truncates its partial output at `execute.max_output_lines` instead of returning the whole buffer.
- **Manual execution log:** actions run by hand in the plan reviewer now reach the console log on submit.
- **Init reporting:** `teddy init` reports how many files actually changed, as `file(s) modified`.
- **Resume instruction:** an injected `resume -m` reply is recorded even when the pending plan does not parse.
- **Tooling and CI:** `make probe` fails loudly when the probe artifact download fails instead of proceeding with a stale log; quality hooks run one per CI step so a failure names the hook; CI runs in parallel per commit and the test job carries a wall-clock cap.
