# TeDDy v0.1.14

Features:
- Editor subsystem overhaul: background editor process with TTY inheritance, persistent temp file storage, GUI editor Popen launch
- CLI editor classification and regression fixes for cross-platform Windows/Unix support
- YOLO guardrail termination message: human-readable guardrail reasons, tuple return type with optional termination message
- Templates extraction to source templates with naming conventions; Makefile and CI documentation templates
- Probe artifact-based retrieval for debugging with simplified Makefile integration

Fixes:
- Fix editor TTY isolation to prevent terminal emulator OSC contamination
- Fix ANSI/OSC escape sequence stripping for editor input and console output
- Fix YOLO guardrail off-by-one, duplicate output, and termination message formatting
- Fix console stdin flush after background editor closes
- Fix pyfakefs compatibility in adapter (replace Path methods with os.path)
- Fix slugify to strip digits and special characters
- Fix Tee handler restoration to prevent logging breakage on restart
- Various Makefile cross-platform fixes for probe and VCP workflows
- Fix session CLI handlers for correct YOLO guardrail colorization
