# TeDDy v0.2.1

## Fixes:
- **Startup banner order:** the update notice now prints directly after the `Checking configurations...` line and before the template and prompt drift advice, instead of on the very first line of the banner.
- **README rendering:** the banner, demo, matrix, and workflow images and the documentation links now use absolute GitHub URLs, so they render on the PyPI project page instead of returning 404, and the diagrams span the full content width.
- **Single publish lane:** the dev pre-release and final release workflows merged into one job that selects the channel from the triggering event and the presence of a release tag, so a release commit no longer publishes a duplicate dev build.
